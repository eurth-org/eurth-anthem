# Anthem

> A friendly note: Anthem is part of Eurth's advent calendar, and its door opens on 21 December 2026. The code is public, the site isn't yet. Please don't spoil the surprise before the door opens.

Anthem writes the words of a national anthem for a fictional nation: verses and a chorus in a hymn metre and rhyme scheme of your choosing, with the nation's own names worked in. It runs entirely in the browser, from phrase banks written for it, with no AI service behind it. It is one of the free worldbuilding tools by [Eurth](https://eurth.org), a worldbuilding and roleplay community since 2004, and will live at anthem.eurth.org.

Nothing is built yet. The plan, and exactly where work stands, is in [roadmap.md](roadmap.md).
